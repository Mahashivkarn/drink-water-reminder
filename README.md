# 💧 Drink Water Reminder

A simple Python desktop notification app that reminds you to drink water every hour.

## 🚀 Features

- Displays a desktop notification every hour
- Simple and lightweight
- Runs continuously in the background
- Uses Python's time module for scheduling
- Uses Plyer for desktop notifications

## 🛠️ Technologies Used

- Python 3
- Plyer
- Time module

## 🧠 Python Concepts Used

This project helped me practice:

- Importing modules
- Using external Python libraries
- `while` loops
- Functions
- Time delays
- Desktop notifications
- Basic automation

## 📦 Installation

Install the required library:

```bash
pip install plyer
```

## 🚀 Usage Example

Run the script:

```bash
python3 water_reminder.py
```

## 📝 Notes

- The script will run continuously in the background
- The script will run every hour
- The script will run for a total of 24 hours
- The script will run until the computer is turned off manually or using a shutdown script/app/tool/etc.

⚙️ How It Works

The program follows this process:

Start Program
     ↓
Display Water Notification
     ↓
Wait 1 Hour
     ↓
Display Notification Again
     ↓
Repeat
